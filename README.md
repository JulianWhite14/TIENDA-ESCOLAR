# 🛒 Sistema de Gestión para Tienda Escolar

## 📖 Descripción del Proyecto
Este repositorio contiene un aplicativo de consola desarrollado en Python, diseñado para gestionar de manera interactiva y eficiente las operaciones básicas de ventas en una tienda escolar. El proyecto es una solución de software enfocada en la simplicidad y la precisión, permitiendo llevar un control detallado de los artículos ingresados y facilitando el procesamiento rápido de las transacciones.

## ✨ Características Principales
El sistema cuenta con un menú interactivo que permite ejecutar las siguientes funcionalidades:
* **Registro de Nombres de Productos:** Permite ingresar y almacenar en la memoria del sistema los artículos que el cliente desea llevar.
* **Asignación de Precios:** Facilita el registro del valor unitario de cada producto, garantizando datos exactos para las operaciones matemáticas.
* **Cálculo de Compras:** Automatiza el procesamiento de los artículos registrados, calculando los subtotales por cantidad y generando el total exacto a pagar (con soporte para lógicas de descuento).
* **Visualización de Información:** Muestra en pantalla de forma estructurada, profesional y legible el detalle de la transacción como si fuera un recibo de compra real.
